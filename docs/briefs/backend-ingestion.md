Parsing libs available: pypdf 6, python-docx 1.2, python-pptx 1.0, openpyxl 3.1 (defusedxml is installed so openpyxl uses it), beautifulsoup4 + lxml.

services/parsing.py (synchronous; called through asyncio.to_thread):
- SUPPORTED_EXTENSIONS tuple: .pdf .docx .pptx .xlsx .html .htm .md .markdown .txt .csv .json. LEGACY_EXTENSIONS = {".doc": ".docx", ".ppt": ".pptx", ".xls": ".xlsx"}.
- class DocumentParseError(Exception) whose message is safe to show users. @dataclass Segment(text: str, page: int | None). @dataclass ParsedDocument(segments: list[Segment], num_pages: int | None).
- def parse_file(path: Path, extension: str) -> ParsedDocument.
  PDF: one segment per page (1-based page numbers), per-page try/except; encrypted -> try decrypt("") else DocumentParseError("Password-protected PDFs aren't supported."); num_pages = page count. DOCX: paragraphs AND tables in body order (walk doc.element.body children for w:p / w:tbl), table rows as "cell | cell". PPTX: one segment per slide (page = slide number) with text frames, tables and notes. XLSX: openpyxl read_only=True, data_only=True, one segment per sheet beginning "Sheet: <name>", rows as "a | b | c", skip empty rows. HTML/HTM: BeautifulSoup(..., "lxml"), drop script/style/noscript/template/svg, include <title>, get_text with newlines. MD/MARKDOWN/TXT/CSV: decode utf-8-sig, fall back to cp1252 then latin-1 (errors="replace"). JSON: pretty-print if valid, else raw text.
  Zip-bomb guard for docx/pptx/xlsx: open with zipfile first; if not a valid zip -> DocumentParseError("The file is corrupted or not a valid .docx file.") (with the right extension); if the sum of file_size > settings.max_uncompressed_mb MB -> DocumentParseError.
  Normalize text: drop NUL chars, strip trailing spaces per line, collapse 3+ newlines into 2. Drop empty segments. If there's no text at all -> DocumentParseError("No extractable text found (scanned PDFs need OCR, which isn't supported yet).") (for non-PDF: "The document contains no text."). If total chars > settings.max_extracted_chars -> DocumentParseError("The document has too much text (over N characters).").

services/chunking.py: @dataclass Chunk(index: int, text: str, page: int | None); def chunk_segments(segments: list[Segment], chunk_size: int, overlap: int) -> list[Chunk]. Recursive split of each segment by separators ["\n\n", "\n", ". ", "? ", "! ", "; ", ", ", " ", ""] into pieces <= chunk_size, greedy merge into chunks <= chunk_size with overlap carried from the tail of the previous chunk (clamped: overlap = min(overlap, chunk_size // 2), aligned to whitespace when possible). Never cross segment (page) boundaries; indices are sequential across the whole document; skip chunks with fewer than 20 non-whitespace chars unless it would leave the document empty. Deterministic and guaranteed to terminate.

services/ingestion.py:
- async def enqueue_document(doc_id: int) -> None: RPUSH redis_client.INGEST_QUEUE.
- async def process_document(doc_id: int) -> None, per SPEC section 7, with its own SessionLocal session(s). Skip unless status is pending/processing. No active embedding model (model_registry.get_active_embedding_model) -> failed "No active embedding model is configured. Ask the admin to enable one." Steps: status processing + commit; parse via asyncio.to_thread(parse_file, storage.stored_path(doc.stored_name), extension-from-stored_name); chunk with settings.chunk_size/chunk_overlap; embed in batches of settings.embed_batch_size via llm.embed_texts; ensure_collection(collection_name(model.id), dim) after the first batch; set model.embedding_dim if NULL; delete the doc's existing points in the target collection AND in its previous collection (doc.embedding_model_id) if different; upsert (vectorstore.ChunkPoint with owner_id/scope/filename/page/text); record ONE embedding usage event for doc.owner_id (sum of batch usages, also when a later batch fails: you paid for what was embedded) with services.usage.record_usage(kind="embedding"); finally re-load the document: if it was deleted meanwhile, delete the points you just wrote and return; else set ready, num_chunks, num_pages, embedding_model_id, error NULL. On failure: status failed with error = DocumentParseError/LLMError message as-is, otherwise "Processing failed: <short reason>" (log the traceback), error truncated to 1000 chars. Missing file -> failed "The uploaded file is missing from storage."
- async def recover_pending() -> int: set processing -> pending and re-enqueue all pending documents; return the count.

worker.py (python -m app.worker): logging like main.py; init_db() with a retry loop (up to ~60s) for DB startup races; recover_pending(); loop: BLPOP INGEST_QUEUE with timeout 5, run process_document in tasks bounded by asyncio.Semaphore(settings.worker_concurrency); invalid payloads are logged and skipped; Redis connection errors -> log + exponential backoff (max 30s) then continue. Graceful shutdown on SIGTERM/SIGINT (loop.add_signal_handler, guarded with try/except NotImplementedError for Windows): stop taking jobs, wait up to 60s for in-flight tasks, close_redis(), close_qdrant(), engine.dispose().

routers/documents.py (prefix "/documents"), exactly SPEC section 6 "Documents":
- GET "" -> caller's private docs + all shared docs, newest first, via storage.document_item(doc, viewer=user, active_embedding_model_id=...).
- GET "/config" -> DocumentConfig (limits from services.usage.user_limits; document_count/storage_bytes over documents the caller OWNS; can_upload_shared = user.is_admin; supported_extensions sorted).
- POST "" multipart: file: UploadFile = File(...), scope: Literal["private","shared"] = Form("private"). Shared requires admin (403). Extension from the ORIGINAL filename (lowercased suffix): legacy -> 415 "Legacy .doc files aren't supported. Save it as .docx and upload again."; unsupported -> 415 listing the supported types. Non-admin quotas (0 = unlimited): document count -> 409; per-file size limit = user_limits(user)["max_upload_mb"] MB -> 413; storage quota (existing owned bytes + this file) -> 409. Stream the upload to storage.stored_path(storage.new_stored_name(ext)) in 1 MiB chunks while computing sha256, aborting with 413 (and deleting the partial file) as soon as the limit is exceeded; never read the whole file into memory. Duplicate (same owner + scope + sha256) -> delete the new file, 409 "This file has already been uploaded." Sanitize the display filename: basename only (split on / and \), remove control characters, collapse whitespace, max 255 chars keeping the extension, fallback "document<ext>". content_type from the upload or mimetypes.guess_type. Insert the row (status pending), commit, enqueue_document (if Redis fails, log a warning; recover_pending will pick it up), return 201 DocumentItem. Delete the stored file on any failure after it was written.
- DELETE "/{doc_id}" -> 204 via storage.delete_document_completely; allowed for the owner of a private doc or an admin for a shared doc; anything else -> 404 "Document not found".
- POST "/{doc_id}/reprocess" -> same permission rule; 400 if no active embedding model; set pending, error NULL, commit, enqueue, return DocumentItem.
