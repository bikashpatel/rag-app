> Detailed requirements given to the original builder for this area. `SPEC.md` is the binding
> contract (paths, JSON fields, SSE events); if this brief and `SPEC.md` disagree, `SPEC.md` wins —

> General rules and the backend foundation summary: [`README.md`](README.md).

Files: backend/app/bootstrap.py, backend/app/routers/auth.py, backend/app/routers/models.py, backend/app/routers/admin.py.

bootstrap.py: "async def bootstrap(db: AsyncSession) -> None" (called from main.py lifespan).
- Admin sync from settings.admin_username (already lowercased) / settings.admin_password: create the user if missing (is_admin=True, is_active=True); if it exists ensure is_admin and is_active, and if the env password no longer verifies, store the new hash and bump token_version. Any OTHER user with is_admin=True (e.g. ADMIN_USERNAME was changed) gets is_admin=False, is_active=False, token_version bumped, and a logged warning. Use hash_password/verify_password from app.security.
- Seed models ONLY when llm_models is empty. Chat: "Claude Opus 5.5" anthropic/claude-opus-5-5 (input 4.0 / output 20.0 USD per 1M), "Claude Sonnet 5.5" anthropic/claude-sonnet-5-5 (2.0/10.0), "Claude Haiku 5.5" anthropic/claude-haiku-5-5 (0.10/0.50), "GPT-5.5" openai/gpt-5.5 (costs null = LiteLLM cost map), "GPT-5.4 mini" openai/gpt-5.4-mini (costs null). Embedding: "OpenAI text-embedding-3-small" openai/text-embedding-3-small (is_default=True, i.e. the active embedding model), "OpenAI text-embedding-3-large" openai/text-embedding-3-large (enabled=False). A seeded model is enabled iff its provider key env var (ANTHROPIC_API_KEY / OPENAI_API_KEY via os.environ) is non-empty (text-embedding-3-large always disabled). Default chat model: Claude Opus 5.5 if the Anthropic key is set, else GPT-5.4 mini if the OpenAI key is set, else Claude Opus 5.5. Leave temperature and max_output_tokens null (Claude 5.5 models reject non-default temperature).
- Idempotent; commit once at the end.

routers/auth.py (prefix "/auth"): exactly SPEC section 6 "Auth". Details:
- Login throttling in Redis (get_redis()): keys "login:fail:user:<username>" and "login:fail:ip:<ip>" (ip = request.client.host or "unknown"). Before verifying, if either counter >= settings.login_max_attempts -> 429 "Too many failed login attempts. Try again in N minutes." (N from the key TTL). On failure INCR both (EXPIRE settings.login_window_seconds when the counter is new). On success delete the username key. Normalize username with strip().lower().
- Use verify_password_async(password, user.password_hash if user else None) so unknown users cost the same time. Inactive users and bad credentials both -> 401 "Invalid username or password". Rehash if needs_rehash. Set last_login_at. Set the cookie with deps.set_session_cookie(response, user) (take "response: Response" as a parameter).
- Provide "async def build_me(db, user) -> schemas.Me" using services.usage.user_limits and usage_summary; use it for login and /me.
- change-password: body {current_password, new_password} (new: 8..256 chars). Env admin -> 400 "The admin password is managed in .env". Wrong current -> 400 "Current password is incorrect". Bump token_version, commit, re-issue cookie, 204.
- logout: 204, clears cookie, no auth required.

routers/models.py (prefix "/models"): GET "" -> list of ChatModel {id, display_name, provider, is_default} using model_registry.list_chat_models_for_user and provider_of.

routers/admin.py (prefix "/admin"): every endpoint depends on deps.get_current_admin. Implement EVERY admin endpoint in SPEC section 6 "Admin" with exactly those shapes. Details:
- Validation (pydantic v2): username 3..64 matching ^[a-zA-Z0-9_.-]+$ (lowercase it); password 8..256; monthly_token_limit/rate_limit_per_min/max_documents/max_storage_mb >= 0; max_upload_mb 1..settings.max_upload_mb_hard; model display_name 1..100; litellm_model 1..200 with no whitespace; kind Literal["chat","embedding"]; api_base null or http(s) URL <= 500 chars; api_key_env null or ^[A-Z][A-Z0-9_]*_API_KEY$; max_output_tokens null or 1..1_000_000; temperature null or 0..2; costs null or >= 0. Treat empty strings for optional string fields as null.
- GET /admin/users: build AdminUser for all users with GROUPED queries (one for this month's usage per user and kind, one for document count + storage bytes per owner), not N+1. Order: admin first, then username.
- POST /admin/users: defaults from settings.default_*; 409 if the username exists; allowed_model_ids must all be existing chat models (422 otherwise).
- PATCH /admin/users/{id}: the env admin account cannot be modified -> 400 "The admin account is managed in .env". Changing password or setting is_active=False bumps token_version. Setting allowed_model_ids replaces the set.
- DELETE /admin/users/{id}: env admin -> 400; for every document they own, storage.remove_document_vectors(db, doc) and db.delete(doc); then the user; commit; then storage.remove_file for each document (files go only after the commit).
- Models: setting is_default=True requires the model to be enabled (else 400 "Enable the model before making it the default") and clears is_default on the other models of the same kind. If an embedding model's litellm_model or api_base changes, its stored vectors are no longer valid: drop its Qdrant collection (vectorstore.drop_collection(vectorstore.collection_name(id))), set embedding_model_id=NULL on documents that used it, set embedding_dim=NULL. DELETE: the active embedding model (is_default embedding) -> 409 "This is the active embedding model. Make another embedding model the default first."; another embedding model -> drop its collection and NULL documents.embedding_model_id explicitly (SQLite doesn't enforce FK actions); chat models -> just delete. POST /admin/models/{id}/test -> services.llm.test_model(model); for an embedding model that succeeds, store embedding_dim.
- GET /admin/stats per SPEC (queue_length = await get_redis().llen(INGEST_QUEUE); stale = ready docs whose embedding_model_id differs from the active model id or is NULL).
- POST /admin/reindex {only_stale: bool = true}: 400 if there is no active embedding model. only_stale -> documents that are stale (as above) or failed; else all documents. Set status "pending", error NULL, commit, then RPUSH all ids to INGEST_QUEUE with get_redis() (do not import the ingestion module; another group writes it). Return {queued}.
- GET /admin/usage?month=YYYY-MM: use services.usage.month_bounds (bad month -> 422). Totals, by_user (join username), by_model (group by model_name, kind), daily (group by func.date(created_at), return "YYYY-MM-DD" strings via str(); portable across Postgres and SQLite), requests = number of chat usage events.
- GET /admin/documents: every document via storage.document_item(doc, viewer=admin, active_embedding_model_id=..., admin_view=True), newest first. DELETE /admin/documents/{id}: storage.delete_document_completely.
